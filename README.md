# My Zootopia API

This project creates a website with animal cards. The animal data comes
from the API Ninjas Animals API.

## Installation

To install this project, clone the repository and install the
dependencies from requirements.txt using `pip`:

    pip install -r requirements.txt

You also need a free API key from API Ninjas. Put it in a file called
.env in the project root, like this:

    API_KEY=your_key_here

## Usage

To use this project, run the following command - `python animals_web_generator.py`.

Enter an animal name, then open animals.html in your browser. If the
animal is not found, the website shows a message instead.
